##### Review the comments that surfaced during the vote to let ConnegP go to Candidate Recommendation [4].

Many (most?) comments are about the definition of profile. This definition is currently being re-written in co-operation with the data-shapes WG and will serve as a basis for SHACL profiling
Other comments are about the Query String Arguments implementations. The plan currently is to let the spec define the Abstract Model and present just one normative implementation - HTTP - and defer all other implementations to a yet-to-be-implemented register of profiles which would include the QSA implementations.
